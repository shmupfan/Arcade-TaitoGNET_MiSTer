G-NET Card Converter

This page turns your MAME files for Taito G-NET games into the zips the Taito G-NET MiSTer core loads. It does the same job as the command-line converter, gnet_tester_zips.py, and writes the same files.

Your files are processed in this browser. Nothing is uploaded.

1 Select coh3002t.zip

The G-NET BIOS set from MAME 0.288.

2 Select your CHD files

The card images from MAME 0.288 (for example raycris/raycris.chd). Each file is recognised from the SHA1 inside it, so file and folder names do not matter.

SetGameCardFile

Not used

    3 Convert

    Games are converted one at a time. Each zip can be saved as soon as it is ready. Keep this tab in view while it runs: browsers slow down tabs that are hidden.

    SetProgressResult

    Unzip this first: the MiSTer needs each gnet_<set>.zip in games/mame, not the bundle.

    Then, on the MiSTer

    1. Copy coh3002t.zip and every gnet_<set>.zip to games/mame on the MiSTer SD card (if you downloaded them as one zip, unzip it first).
    2. Get the core and MRAs. With Update All and the shmupfan database added (see the guide below), they install automatically: the core to _Arcade/cores, the main MRAs to _Arcade, other versions to _Arcade/_alternatives. Without Update All, copy them from the releases folder to the same places.

    Step by step guide: INSTALL.md. The zips hold game data made from your own files, so keep them to yourself.

    Runs offline: you can save this page and open the saved file. @BUILD@
